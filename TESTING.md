# Практическое задание №7 — тестирование системы

## Цель

Проверить систему как единое целое: пользователей, баланс, списание кредитов, ML-запросы, историю операций и обработку задач worker.

## Что покрыто автоматическими тестами

### Пользователи
- создание нового пользователя;
- повторная регистрация того же пользователя;
- авторизация;
- повторная авторизация;
- ошибка при неверном пароле;
- запрет доступа к защищённым endpoint без токена.

### Баланс
- получение начального баланса;
- пополнение баланса;
- получение обновлённого значения после пополнения.

### Списание кредитов
- списание за успешный ML-запрос;
- запрет выполнения при недостаточном балансе;
- отсутствие списания при некорректных входных данных;
- возврат кредитов при ошибке worker.

### ML-запросы
- успешный синхронный запрос и получение результата;
- некорректные входные данные;
- частично валидные данные;
- постановка асинхронной задачи в RabbitMQ;
- сохранение статуса асинхронной задачи;
- обработка задачи worker для `demo_model`.

### История
- сохранение истории ML-запросов;
- сохранение credit/debit/refund транзакций;
- связь debit-транзакции с ML-запросом;
- история асинхронных задач.

## Файлы тестов

- `app/tests/test_orm.py` — ORM и бизнес-логика;
- `app/tests/test_system.py` — сквозные REST API сценарии;
- `app/tests/test_worker.py` — обработка задач worker и refund при ошибке.

## Запуск

```bash
cd app
pytest
```

В Docker Compose:

```bash
docker compose exec app pytest
```

`app/pytest.ini` добавляет корень приложения в Python path, поэтому отдельный `PYTHONPATH=/app` не требуется.

## Ожидаемый результат

Все тесты должны завершаться без ошибок. GitHub Actions запускает тот же набор тестов автоматически для ветки `task-7-testing` и pull request.

## Вывод

Критичные пользовательские сценарии проверяются не только на уровне отдельных функций, но и через REST API с реальной бизнес-логикой и тестовой базой данных. Отдельные тесты worker проверяют успешную обработку асинхронной задачи и компенсацию списанных кредитов при ошибке обработки.
